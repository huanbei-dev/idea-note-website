# 灵感笔记官网

灵感笔记（连接 Q助理 的极简卡片式记录工具）官网首页。单文件静态页，无任何构建依赖。

## 页面内容

- **首屏 Hero**：产品真实桌面端界面 + 多端下载入口（Windows / macOS / Android / iOS）
- **功能**：快速记录、#标签整理、打卡热力图、⌘K 全局搜索、每日回顾、微信输入
- **多端同步**：Q助理 扫码登录、双向同步、本地缓存离线可用
- **下载区**：四端下载卡片；macOS 区分 **Apple 芯片（arm64）** 与 **Intel（x64）** 双版本

设计语言取自应用本体：米黄纸底 `#f4e9d3`、深棕墨色 `#5d4430`、橙棕强调 `#b6774c`。

## 本地预览

```bash
open index.html        # 双击即可，无需构建
```

## 部署

推送到 GitHub 后启用 Pages（Settings → Pages → Deploy from a branch → main / root），或部署到任意静态托管。

## 自定义提示

- 下载按钮目前为占位：点击会提示「下载地址即将上线」。发布安装包后，在 `index.html` 的下载按钮 `data-tip` 绑定处替换为真实链接即可（顶栏、Hero、下载区共用同一套绑定）。
- 桌面端安装包命名约定：`灵感笔记-Setup-1.1.0.exe`（Windows）、`灵感笔记-1.1.0-arm64.dmg` / `灵感笔记-1.1.0-x64.dmg`（macOS）。
